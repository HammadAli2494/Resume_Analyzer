# AI Resume Screening

Supervised ML system that scores how well a resume matches a job description, with a React UI and Django API for screening and recruiter workflows.

## Highlights

- **Trained classifier** on labeled resume–job pairs (not rules-only)
- **Feature engineering:** TF-IDF, semantic similarity, skill overlap (spaCy)
- **Recruiter flow:** job postings, batch upload, ranked candidates, CSV export
- **Data labeling:** build and verify training data in the UI

## Repository layout

```
backend/     Django REST API, JWT auth, SQLite
frontend/    React + Vite + Tailwind
ml/          Training, evaluation, model artifacts
docs/        ML guide and generated reports
scripts/     setup.ps1 — migrate, seed, train
```

## Quick start

### 1. Setup (once)

```powershell
cd backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm
cd ..
.\scripts\setup.ps1
```

### 2. Run

```powershell
# Terminal 1
cd backend
.\venv\Scripts\activate
python manage.py runserver

# Terminal 2
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173**

| Route | Description |
|-------|-------------|
| `/` | Screen a resume against a job description |
| `/jobs` | Manage postings and batch-screen candidates (login) |
| `/labeling` | Create or import training labels |
| `/evaluation` | Model metrics and baseline comparison |

## Machine learning

Training uses verified pairs from the database (seed data included). See **[docs/ML.md](docs/ML.md)** for details.

```powershell
cd backend
python manage.py train_ml --real-only
python manage.py generate_ml_report   # writes docs/ML_REPORT.md
```

## Portfolio / sharing

Do not zip `backend/venv`, `frontend/node_modules`, or `backend/db.sqlite3` — others run `setup.ps1` locally. Trained model files under `ml/models/` are generated by training.
